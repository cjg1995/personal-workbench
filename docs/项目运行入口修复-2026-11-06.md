# 项目运行入口修复（0.1.41）

`refsys-ui` 原先由项目的 `devServer.open: true` 与工作台各打开一次浏览器。工作台启动 Vue / UniApp 时现在通过 `BROWSER=none` 禁用工具链自行打开页面，确认服务就绪后统一打开一次，原项目配置不改动。

易居通、项目经理、工人、司机四个 APP 各使用独立 Chrome 实例，用户配置位于工作台数据目录的 `browsers/` 下，按项目和工作目录区分。新浏览器会话默认启用 320 × 652 手机模拟、触摸、手机 UA、右侧开发者工具和网络面板；重复打开会唤起已有页面并保留当前路由。配置和 Cookie 独立保留，不读取日常 Chrome 的配置。浏览器窗口独立于项目服务，停止开发服务不会关闭浏览器。

客户小程序移除“打开 IDE”；推荐官小程序的对应入口改为“打开开发者工具”。推荐官小程序“启动”执行编译监听，确认 `mp-weixin` 输出后自动通过本机微信 CLI 导入 `unpackage/dist/dev/mp-weixin`。没有编译监听时点击“打开开发者工具”，会先执行这条启动链；已监听时直接重试打开工具。CLI 失败保留编译监听，并在任务中心显示失败阶段。

Windows 进程查询有时会在刚启动时返回空的 `ExecutablePath`。启动阶段现在等待完整的进程身份后再保存，避免服务已启动却无法核实或停止。
