# 0.1.60 项目管理与代码编辑器

项目管理保留启动、停止、状态、IDE、目录、规则和日志操作，新增「代码编辑」入口。每个项目复用一个独立编辑窗口，切换项目时不会替换另一个项目的编辑内容。

已执行 `npm run package` 和 `node scripts/reinstall.cjs`。实际安装程序的 FileVersion 为 0.1.60；0.1.59 → 0.1.60 的隔离升级测试保留了记录和月报关联。随后使用安装目录中的程序完成 Java 编辑窗口导航测试，通过了多实现、引用、父方法、鼠标跳转、JDK 源码和外部文件更新验证。

安装包为 `D:\personal-workbench\release\PersonalWorkbench-0.1.60-Setup.exe`，SHA-256 为 `1c9c3e5a71d0daad434382621f5c41ebf13da4db4def9d59faad241db1122f0c`。

## 编辑与交互

- 左侧目录按需展开，与当前文件联动；分隔条可拖动。目录和代码独立滚动。
- 右侧复用 Git Diff 的 Monaco 主题、字体与显示设置；一个编辑器切换多个独立 model，Tab 切换保留撤销栈、光标和滚动位置。
- 未保存文件以圆点标识。关闭文件、编辑窗口或整个工作台时均提供保存、放弃、取消。
- 保存写回原项目文件，保留 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM、GB18030 和 Monaco model 的换行格式。保存前比较原始字节的 SHA-256，外部修改时先选择取消、重新加载或明确覆盖。
- 保存期间继续输入会保留未保存标识；同一 Tab 的保存串行执行。
- 打开文件监听磁盘变化；Java 工程额外监听关闭文件和构建配置变化，通知语言服务更新。关闭窗口释放 model、文件监听和语言服务。
- 重开保留最近 20 个文件、光标、滚动位置、目录宽度和最多 200 个历史位置。未保存内容仍需用户在关闭时作出选择。

## 导航

| 操作 | 行为 |
| --- | --- |
| Ctrl+点击、Ctrl+B | 跳到声明或定义；处于声明时显示引用与调用 |
| Ctrl+Alt+B、Ctrl+Shift+点击 | 跳到具体实现 |
| Ctrl+U | 被重写的方法；类型位置跳到父类型 |
| Alt+F7 | 全部语义引用与调用位置 |
| Ctrl+Shift+R | 模糊匹配项目文件并打开 |
| Ctrl+F | 当前文件查找 |
| Ctrl+Shift+F | 项目文本搜索，按文件分组，显示行号和代码片段 |
| Alt+←、Alt+→ | 后退、前进 |
| Ctrl+S、Ctrl+Z、Ctrl+Y | 保存、撤销、重做 |

单结果直接跳转，多结果使用紧凑列表，支持上下键、Enter、Escape、筛选和代码片段。语义结果列表使用虚拟滚动，不会为了显示性能而截掉引用。跳转会打开目标文件、定位并暂时高亮；JDK 与依赖的虚拟源码以只读 Tab 打开。

## 语义实现

Java 的定义、实现、引用、补全、悬浮信息、参数提示、诊断来自 Eclipse JDT LS。Ctrl+U 使用 JDT 的 `java/findLinks` 和 LSP type hierarchy。没有 Service/Impl 命名推断或文本搜索替代语义跳转的逻辑。

语言服务读取完整工程，交给 JDT、m2e、Buildship 解析 Eclipse、Maven 和 Gradle 结构、模块与依赖。使用已有项目 JDK、JAVA_HOME 及常见安装目录中的 JDK，按 release 元数据注册 Java 版本；读取用户 Maven settings 和工作台 Maven 目录的全局 settings。未保存内容通过版本化 didOpen/didChange 同步，不必先保存才能导航。

安装包附带 JDT LS 1.64.0-202611062158 和独立 Temurin 25.0.5+8 运行时。服务的启动缓存、索引和 Eclipse 元数据位于工作台用户数据目录的 `java-workspaces`，按项目绝对路径隔离；启动参数禁止在源码根生成 Eclipse 元数据，关闭自动构建以避免改写项目原有编译输出。界面在后台导入和索引时仍可操作。

TypeScript/JavaScript 使用 Monaco 的 TypeScript worker，后台读入项目中的 TS/TSX/JS/JSX，提供补全、诊断、跨文件定义和引用。Ctrl+B、Alt+F7 使用编译器返回的符号结果。其他语言保留 Monaco 语法高亮、编辑、保存和文本搜索。

文件名搜索与文本搜索由随安装包提供的 ripgrep 执行；文本搜索属于独立功能，不参与代码语义判断。项目文件清单短期缓存，生成目录和 Git 忽略文件不进入搜索；目录正文按需读取。输入新查询或关闭编辑窗口会取消旧的文本搜索进程，搜索跳过超过 4 MB 的文件。

## 验证

- `verify-editor-language.cjs` 创建三个真实 Maven 模块，断言准确 URI 与行号，覆盖跨模块调用、String/int 重载、两个实现、继承方法、参数定义、父方法与父类型、引用、未保存修改后的重新解析、Java 补全和诊断。
- `verify-editor-real-java.cjs` 从真实 refsys 工程复制约 775 个源码/配置文件到隔离目录，验证注解定义、六处注解引用、工具类与重载方法，以及 Apache Commons 依赖源码。原工程只用于读取。
- `verify-editor-navigation-ui.cjs` 用 Playwright 驱动真实 Electron 编辑窗口，覆盖 Ctrl+B、Ctrl+Alt+B、多实现键盘选择、Ctrl+U、Alt+F7、历史返回、JDK 虚拟源码、Ctrl+点击和 Ctrl+Shift+点击，并验证外部修改一个关闭的 Java 文件后实现结果更新。
- `verify-editor-ui.cjs` 覆盖多 Tab、实际写盘、撤销重做、文件/全局搜索、历史、外部冲突取消与覆盖、未保存关闭取消与放弃，以及关闭主窗口时的保存保护。
- `verify-editor-ts-ui.cjs` 在两个 TS 模块中验证跨文件定义与返回。
- `editor-files.test.ts` 验证编码/BOM/CRLF 保留、磁盘冲突阻断、路径越界拒绝，以及 Node/ripgrep 两条搜索路径。
- `npm test` 完整回归 99/99 通过；主窗口 UI 回归和 Git Diff 的分支、差异导航、Revert、未保存保护回归均通过，没有页面异常。更新后的文件搜索/编码/冲突单测也单独通过。
- 大项目实测 `homeproject` 35,500 个文件：缓存条件下文件清单约 218 ms、模糊查找约 42 ms、取前 500 处文本结果约 69 ms。同时运行完整 Git/项目回归及语言服务时，文本搜索曾耗时约 50 秒，不能把缓存数据当作冷启动保证。refsys 的 JDT 导入与语义验证在单独运行时约 7–15 秒，在并发回归期间约 41 秒。索引和搜索均在后台执行，界面保留搜索/索引状态。

## 使用边界

- Java 语言服务依赖工程的真实 classpath。缺失的私有依赖、损坏的构建配置、未配置的项目 JDK 会影响解析；首次 Maven 导入可能需要联网下载依赖。
- Java 7 尚未列为完整支持。最新 JDT LS 对 Java 7 模块的实现查找在验收中返回不完整；普通编辑和基础跳转仍可用，但不能据此保证 Java 7 的所有继承和多态关系。项目管理中的外部 IDE 入口继续可用。
- TS/JS 目前只认证定义和引用导航；实现与父方法操作明确提示服务暂不支持。项目索引上限为 3,000 个文件或约 16 MB 文本；未集成 Vue SFC、tsconfig extends/paths 和 npm 类型依赖的完整解析。
- 单文件编辑上限 4 MB。全局文本搜索显示前 500 处，并明确标明上限；语义引用结果不受此文本搜索上限影响。
- 注解处理器生成的成员、Lombok、运行时 Spring 代理和依赖注入关系尚未完成专门验证，不承诺与 IntelliJ 的专用框架插件等效。
