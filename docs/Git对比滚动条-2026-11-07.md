# Git 对比滚动条与 Revert（0.1.43）

双栏对比改为原始代码最左侧、右侧代码最右侧各一条垂直滚动条。关闭 Monaco 的双列差异概览及内部垂直轨道，中央只保留行号与 Revert，不再出现中间一条、右侧两条的布局。左右轨道整合增删改标记，支持拖动、轨道点击、滚轮及方向键 / PageUp / PageDown / Home / End，两侧仍由对比编辑器同步滚动。水平滚动条保留，单栏模式只显示右侧一条垂直轨道。

滚动条绑定稳定的编辑器容器，切换文件、重新加载模型、修改字号、缩放窗口及拖动分栏后仍跟随实际文档尺寸。组件监听与 DOM 在窗口销毁时统一释放。

中央 Revert 改为 20 × 20 SVG 双箭头，增加边框、浅色背景与悬停反馈，默认可见。它仍立即回滚对应代码块，保留暂存区，并支持 Ctrl+Z / Ctrl+Y。
