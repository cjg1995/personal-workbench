## 已实现

- 本地文件搜索、按状态过滤、排序、批量选择、右键菜单和键盘导航。混合暂存状态独立保留，不默认执行 `git add .`。
- 单文件和多文件 Stage/Unstage、手动 Commit、Commit and Push、Amend、Hook 输出和失败结果。提交的是当前 Index 中的全部内容，勾选文件仅用于明确的文件操作。
- Fetch、显示上游与策略的 Pull、带目标和 Commit 预览的 Push。推送使用明确 Remote 和目标分支，不默认强制推送，沿用系统 Git 凭据。
- 本地/远程分支查询、新建、Checkout、重命名、安全删除、比较、Merge、Rebase，以及从 Commit 建分支。
- Git Log 按 150 条增量读取，显示父子拓扑、作者、日期、Hash、分支/Tag、详情和修改文件；支持消息筛选、文件历史、两个 Commit 比较、Revert、Cherry-pick、受限的 Undo Last Commit。
- Stash Push、说明、包含未跟踪文件、Diff、单独查看未跟踪文件、Apply、Pop、确认 Drop。冲突时保留 Git 的真实状态。
- Merge/Rebase/Revert/Cherry-pick 状态识别和 Continue/Abort；Rebase/Cherry-pick 支持 Skip。切换、拉取、合并和变基前拒绝静默丢弃本地修改。
- 三方合并从 Index 的 1/2/3 阶段读取。显示共同基准的两侧修改高亮、当前结果、未解决块数量，支持按块接受左侧、右侧或两侧、手动编辑、保存并暂存、接受修改/删除冲突中的删除结果，再继续当前操作。Rebase 的阶段 2/3 使用真实来源标签。
- 双击文件打开独立、默认最大化的原生窗口，同一项目复用。文件栏约 240px、可拖动/收起；支持 F11、F7/Shift+F7、Ctrl+F、Ctrl+S。
- Monaco 完整文本双栏/单栏对比、行内差异、同步滚动、字号、换行、深浅主题、忽略首尾空白和折叠未修改区域。默认只读，操作模式需主动开启。
- 支持 HEAD ↔ Working Tree、HEAD ↔ Index、Index ↔ Working Tree、Commit/分支之间，以及历史版本 ↔ 当前文件工作区。
- 逐块 Stage/Unstage 和未暂存块回滚使用 Git 原生 Patch 和 `git apply --check`，真实修改 Index/工作区。操作前核对 HEAD、Index 和文件内容；整文件回滚在确认前后也核对内容。外部修改不会被过期 Diff 静默覆盖。
- 同一公共 Git 仓库的写操作串行，并与原一键提测的任务锁互斥。窗口限制 Node、导航、权限和 IPC；只允许访问该窗口绑定的项目。

## 限制与未实现增强

- Interactive Rebase 未实现，普通 Rebase 及恢复操作已实现。
- Revert/Cherry-pick 合并提交需要指定 mainline，目前明确拒绝，需用外部 Git 工具处理。
- 逐块操作限普通、可完整读取的 UTF-8 文本修改。新增/删除、重命名、模式变更、二进制和旧编码使用整文件操作；不做字符串拼接回滚。
- 单文件正文上限为 4 MiB。超过上限不加载完整编辑器正文。二进制和旧编码不做三方文本覆盖或自动转码，需在外部解决后暂存并 Continue。
- Undo 的未推送判断依据本地远程跟踪引用，执行前应先 Fetch；不提供默认 Force Push 或 Reset Hard。
- 远程写操作测试使用本地 bare remote，未向真实业务远端推送，也未验证所有 SSH、代理和企业认证组合。沿用系统 Git 的认证与 Hook 配置。
- 构建会提示 Monaco 独立窗口的约 3.2 MB 脚本块较大。资源只在独立入口加载，已本地打包；Monaco 作为构建依赖，不重复携带完整源码目录。
