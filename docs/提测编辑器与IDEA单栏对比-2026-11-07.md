# 提测编辑器与 IDEA 单栏对比

交付版本：0.1.48。

## 行为

- UniApp、refsys-ui、refsys-wechat 的提交说明在更新远程前就显示并可编辑；更新前后保留同一说明，草稿按项目持久化，重新打开待确认任务时可以继续修改。
- 提测右侧使用与独立 Git 对比相同的 Monaco 主题、语言识别、字号和行距，固定为单栏模式。可编辑工作区的文本内容，Ctrl+S 保存；离焦、切换文件、关闭弹窗、离开页面及关闭应用时，未保存代码可选择保存、不保存或继续编辑。同一次离开只显示一个询问。
- 提测保存初始阶段保留已有暂存内容，刷新提交清单和指纹；最终确认阶段沿用原提测任务的写锁，保存后按原规则更新当前文件的暂存内容和最终确认指纹。普通 Git 写操作仍不能抢占提测锁。
- 连续保存、Revert 后文件变干净、Ctrl+Z 后再次 Ctrl+S，均能继续更新提交内容。受保护的本地测试配置在提测编辑器中只读。
- 使用文件快照校验防止覆盖 IDEA 等外部修改。保存期间其他文件发生变化时不自动接受新的提交指纹，保留工作区代码并阻断旧确认继续提交。

## 与 IDEA 对齐

- 双栏：修改行背景蓝色，段内新增文字绿色；纯新增块绿色，删除灰色。Revert 使用 `>>`。
- 单栏：旧行灰色，新行浅绿色，新增文字较深绿色，纯新增块绿色；上下显示旧版本和工作区信息及各自换行符。Revert 使用回退箭头。
- 提测弹窗也使用上述单栏样式和回退图标。点击 Revert 立即保存，手工修改及撤销后的内容可 Ctrl+S 保存。
- 文件列表和代码各自滚动，弹窗没有整体滚动条，提交说明和确认按钮固定在底部。
