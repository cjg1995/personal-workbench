# Git 对比 IDEA 交互调整（0.1.42）

工作区比较默认可编辑，移除“操作模式”开关。HEAD / 暂存区 / 历史版本的可写范围仍由实际比较来源确定，暂存区和版本间比较保持只读。

代码块旁的 `»` 与工具栏 Revert 直接将该块恢复为左侧内容并保存工作区，不弹确认框，也不要求先保存其他编辑。实现使用当前编辑文档的差异与撤销栈，保存时只更新磁盘身份，不重建编辑器。Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做会同步保存，最后一处差异消失后仍保留文档，便于撤销。普通手动编辑可以使用 Ctrl+S 保存；外部文件、HEAD 或 Index 变化仍会使旧身份失效。

窗口按给定 IDEA 经典浅色截图调整：紧凑工具栏、双栏/空白/高亮下拉框、中央原始行号、工作区行号及代码块箭头、绿色新增、灰色删除、蓝色修改、无斜纹填充。真实选区同时覆盖整行背景和单词背景，绿色新增块选中后显示统一蓝色。Git 操作工具栏默认折叠，通过顶部“Git 操作”打开；深色、单栏、查找、文件列表与三方冲突功能保留。

跨文件导航到达当前文件的首处或末处差异后，先显示“再按一次跳到上一个文件 / 下一个文件”的中文提示。同方向再点一次，或按 Shift+F7 / F7，才跨文件。文件内导航直接定位，搜索过滤和列表边界保持生效，未保存编辑的离开保护保留。
