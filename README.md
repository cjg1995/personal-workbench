# 个人工作台

Windows 本地桌面应用，使用 Electron、Vue 3、TypeScript、Vite 和 Electron 内置 SQLite。源码、安装包和验收材料均在本工作空间。HomeProject、推荐官是被管理的既有项目，本目录不是它们的后端源码目录。

需求以 PRD v1.1 和用户后续决定为准；界面依据本目录 14 张新设计图实现。首次打开没有示例记录、虚构分支或模拟运行结果。

## 启动与安装

当前源码与安装包版本为 0.1.3。安装包为 `release/PersonalWorkbench-0.1.3-Setup.exe`，选择当前用户可写目录安装，不需要额外部署数据库或服务器。本机也可直接打开 `.local/installed-app-0.1.3/个人工作台.exe`；切换版本前先保存并退出已运行的工作台。旧运行目录暂保留，以继续管理其已经启动的后台服务。

从源码运行，在本目录执行以下命令。开发使用 Node 22.20.0；首次安装依赖需要联网，Electron 下载按锁定版本和官方 SHA256 核验。

```powershell
npm ci
npm run build
npm start
```

常用开发命令：

```powershell
npm test
npm run verify:ui
node scripts/verify-workflows.cjs
node scripts/verify-review-fixes.cjs
node scripts/verify-feedback.cjs
npm run package
```

界面验收脚本使用本机已有的 Playwright，不是应用运行依赖；其他开发机需自行提供该测试工具。真实项目验收脚本会操作原工具链，先阅读下方验证边界。

`npm run build:tomcat` 只在修改 `src/native/WorkbenchTomcat.java` 后需要，使用 JDK 编译 Java 8 兼容组件；已核对的字节码随源码和安装包提供。工作台自身的记录、审查、月报不依赖 Java；运行或构建被管理的 Java/Android 项目需要其原有工具链。

## 使用与数据

首次使用先在“设置”核对实际工具、11 个项目路径和默认姓名。提交、打包先检查并预览，再由可见按钮启动；任务中心保存实际阶段。项目运行只停止拥有且创建时间、执行文件、实例标识均匹配的进程；外部实例交给原工具管理。端口冲突会阻断，不自动改端口。

默认数据目录为 `%LOCALAPPDATA%/PersonalWorkbench`。记录存于 `workbench.sqlite`，TXT 原文快照、任务日志和 APK 副本存于相应子目录；不会写回原 TXT。备份包含记录、配置、月报、审查和 TXT 快照；源码、APK、外部业务工程和日志仅保留路径引用，需另行保管。

当前备份恢复上限为单库/压缩包 128 MB、展开内容 256 MB，超限报错且保留原数据。代码审查在后台读取，支持进度和取消；内置正文上限为单文件 512 KB、单快照 16 MB，差异每页展示 300 行，单行超过 2,000 字符时显示前缀并提示查看编辑器。超过 200 个未跟踪文件时，先按大小和时间检测变化，选中后读取正文并保留内容摘要供复查；超大文件仅核对元数据。审查历史分页读取摘要，正文按所选快照读取。

项目启动和开发者工具任务结束后发送 Windows 通知，点击恢复工作台并打开对应任务。通知受 Windows 通知开关和专注模式影响；发送失败会记录在任务结果中。

开发验收使用隔离数据目录，例如：

```powershell
npm start -- --data-dir=D:/personal-workbench/.local/manual-acceptance
```

`scripts/verify-real.cjs` 会启动真实业务工具或服务，不能当作普通无副作用测试运行。本次联调已按 [具体计划](docs/真实联调计划.md)取得批准；后续重新联调仍应核对当时对象和影响。Git 写操作的自动验证全部使用 `.local/` 内临时仓库与本地 bare remote。

安装包目前未作发布者代码签名。Windows 10 x64 已实机验证，Windows 11 尚无实机证据；APK 未安装到手机，TAPD 只验证客户端入口。月报在本机 Word 验证打开和排版：无顶部月份姓名标题，截图位置只留一个空行；学习成长和工作计划多条内容分别从 1 编号，序号缩进与主要工作一致。

## 目录

- src/core/：原生业务编排、数据与保护。
- src/main/：Electron、受控 IPC 和独立进程监督。
- src/renderer/：业务界面。
- src/native/：使用原 Tomcat 配置部署应用的 Java 组件源码。
- assets/：空白月报、应用图标和已核对的运行组件。
- tests/、scripts/：回归测试、构建及隔离验收程序。
- docs/：需求、交互与开发交接。
- design/：图册、设计说明与生成记录。
- design/images/：14 张最终原图，统一按页面编号命名，无过程稿和重复图包。
- release/：当前安装包与解包运行目录。
- .local/：隔离的验收数据、证据与临时仓库，不混入默认用户记录库。
